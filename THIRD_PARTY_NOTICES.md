## MAVLink C Library

This project includes the MAVLink C headers generated from the official MAVLink message definitions.

MAVLink is an open communication protocol for unmanned vehicles.
The generated MAVLink C headers are licensed under the GNU Lesser General Public License (LGPL).

The headers are included unmodified and are used strictly as a message definition dictionary.
No official MAVLink parsing or runtime utilities are used.
